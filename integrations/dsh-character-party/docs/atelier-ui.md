# 工坊委托与角色模型 UI

2026-11-09，已落地到 DSH 工坊委托及 GAL 内嵌入口。

本轮采用深海蓝、黄铜细线、象牙色信笺，与现有深海女仆工坊共用字体、角色原画和外框。角色立绘与业务逻辑保留。

## 界面

- 同伴导航：22 位角色的切角头像包框、岗位说明、当前选中标记。宽窗口为独立滚动名册，小窗口为横向角色签。
- 委托编辑：角色原画、对应元素纹章、主题说明、象牙色委托笺、模式页签及交付按钮。多人协作名单在信笺内单独滚动。
- 记录与记忆：状态、时间、原始委托、成果、用量与来源分层展示，长内容保留完整的滚动与换行。
- 角色与模型：固定金饰外框、标题、使用配置导航和保存操作。角色型号列表独立滚动，角色头像与主题色保持对应；搜索无结果有明确提示。
- API 来源：来源条目、配置状态和编辑表单沿用同套材料，密钥输入仍为密码框。
- GAL 入口：重新设计标题栏、返回与关闭控件。游戏内两层模态面板各自约束滚动范围。

## 可复用美术

`assets/workshop` 包含委托信笺、头像包框、22 个角色元素 SVG、控制图标、角色主题色表，以及深色和金色按钮的五态 SVG。按钮不带文字，便于在引擎中复用；按下时的 1 px 位移由运行时处理。

`source/workshop` 包含可编辑样式、前端模块快照、入口框体和 SVG 导出脚本。网页运行时通过内联 SVG、CSS 与已有原画呈现，静态资源仍使用原服务路径。

## 验证

- 前端及项目语法检查通过，既有 25 项测试通过。
- 实页检查 22 位角色选择、单人/协作/交流模式、委托回调、模型绑定草稿、角色搜索、配置复制与保存回调、API 编辑取消、编辑内容保留。
- 独立页面检查 1440、1024、768、390 像素宽度；GAL 内嵌检查 1664、390 像素宽度。
- 模型列表滚到底时，标题、配置导航与保存按钮保留在框内，最后一位角色可达；没有水平溢出。
- 模型目录载入前后都保持明确的网格行，空提示消息不会挤走保存栏。
- 修正父级游戏按钮样式影响手机关闭按钮的问题；关闭后焦点回到入口。
- 没有 JS 异常或素材 404。两次回调验收请求均在浏览器中拦截，没有保存实际配置、创建委托或调用付费模型。
