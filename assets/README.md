# 美术与 UI 资产

- default：稳定素材键对应的头像、立绘、背景和上游许可。
- packs/actions：完整动作立绘；按角色 / 动作分类。
- packs/scenery：场景背景。
- packs/signal、packs/ui：游戏 UI、字体、图标、封面与框体。
- packs/wardrobe：已完成的服装立绘。
- packs/embedded：从 JavaScript 外置的框体与装饰媒体。
- packs/manifest.json：运行文件白名单、角色动作、尺寸与 SHA256。

新资产后续按 docs/ASSET-SYNC.md 导入。本目录不包含新的未验收生图，也不保存用户上传、存档、生成 CG 或 API key。
