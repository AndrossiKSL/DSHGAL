# 源码与素材分开分享

程序代码、项目编写的 UI 实现和文档沿用 MIT，保留原作者版权及声明。`LICENSE.md`、`NOTICE.md` 与 `THIRD_PARTY_LICENSES.md` 描述上游美术的独立许可；不能将整包图片统一改标 MIT。

默认美术包含 CC BY-NC-SA 4.0 图片及 MIT 桌宠图集。扩展人物沿用原始设计的署名与条件，生成改绘不消除上游条件。没有完整再分发依据的个人素材只留在本地素材包，不应直接作为纯 MIT 开源资产发布。

本迭代把原始生图索引和导入结果记在 `docs/art-import.json`，里面记录文件名、哈希与成品状态，不包括个人绝对路径或凭据。它是来源追踪记录，不替代许可文件。

可分享的纯代码归档：`npm run package:share`，输出 `artifacts/DSHGAL-2.2.4-code.zip`。归档排除图片、字体、截图、原始生成图、构建 bundle 和用户数据，仅保留代码、资源契约和许可声明。使用当前美术主题前需自行提供有权使用的素材包；复制 `assets/default` 和 `assets/packs` 后构建。不要将本地全美术运行包与纯代码包混为同一种许可。

完整分享 ZIP 带当前运行美术、UI、预构建产物及配套工坊，保留各自来源和许可声明。纯代码 ZIP 用于不附带美术的源码交流。两个分享包均排除 Git 历史、个人绝对路径、旧试验记录和本机数据。公开发布前必须执行文件白名单、许可与脱敏检查，流程见 PUBLISHING.md。
