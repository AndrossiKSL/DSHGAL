# 2.2 审查与迭代记录

## 基线

原项目 package 2.1.0，最新封包标签为 2.1.1-Persona，提交 9df3b94。审查时原仓库另有未提交的开场、地图、关系与剧情修改。本版本保留该工作树，不覆盖线上 DSH 的安装、凭据或存档。

## 修复

- 修复 embed-art 生成文本中使用字面量转义换行的问题，并改为生成明确的资源 URL。
- 默认图片和 7 项额外内嵌媒体外置，客户端由 39.80 MB 降至约 1.07 MB。保留逐文件许可；媒体路由只允许清单文件，不允许任意路径。
- 默认禁用 sourcemap，允许 WHG_SOURCEMAP=1 开发调试，发布审查拒绝 map。
- 移除个人 SSH 配置默认绝对路径，改用 WHG_SSH_CONFIG；独立 Hermes 模式默认关闭自动生图。
- 增加独立启动、DSH 默认后端、Hermes 本地存档和 ACP 委托；权限保持单次用户选择，取消和重启后不会自动重放工作。

未删除存档仍可能引用的旧角色素材、旧形象 ID、动作 ID，也未修改来源生图目录。第三方素材许可保持独立；纯代码导出排除所有媒体与构建产物。

## 保留的限制

Hermes 委托目前提供单工作队列、原会话续接和权限处理，不复刻 DSH 工坊的多人依赖图、模型分工界面及成果校验服务；这些能力在默认 DSH 后端仍由原工坊提供。剧情接口与 Agent 执行是分开的连接。

大型剧情宿主文件继续保留，以免一次抽取同时改写世界线和存档格式。已有旧形象和剧情标识保留兼容。素材许可需要随文件保留，纯代码包不含美术；352 张计划动作未生成。没有进行公开仓库推送或 npm 发布。
