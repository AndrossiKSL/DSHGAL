# Windows 桌面版

双击 `DSHGAL-2.2.4-Portable.exe`，打开独立游戏窗口。程序包含 Chromium、Node 运行时、游戏前端和当前美术；无需单独安装 Node，不显示控制台，也不打开外部浏览器。

首次启动若检测到本机 3080 上已有 GAL 后端，会复用它进入游戏；否则在窗口内打开连接设置，选择已有的 DSH 或 Hermes。AI 对话与工作仍需要这些后端和可用模型，桌面包不包含模型权重或个人凭据。

- F11 切换全屏，Esc 退出全屏；Alt 显示原生菜单。
- 菜单「游戏 → 连接与后端」修改后端连接；「返回标题」回到游戏标题。
- 画面内的「退出游戏」也会退出桌面应用；网页版继续保留返回标题的行为。
- 重复打开会聚焦已有窗口；关闭窗口会退出应用自有的服务。已有 DSH 或 Hermes 宿主进程不会被终止。
- 便携版数据放在 EXE 同目录的 `DSHGAL-data`，包含配置、独立存档和日志。分享时只发送 EXE，不发送个人数据目录。
- DSH 存档继续由原 DSH 保存。网页版 `.local` 和便携版数据目录相互独立，不自动覆盖或搬运用户存档。
- 源码开发使用 `npm run desktop`；制作便携 EXE 使用 `npm run package:desktop`。下载缓存可用 ELECTRON_CACHE 与 ELECTRON_BUILDER_CACHE 设置，构建临时目录使用 TEMP/TMP。

桌面窗口使用隔离且无 Node 权限的渲染环境，仅允许加载本应用的回环地址；Agent 文件能力仍在后端处理。完整源码与 Agent 部署 ZIP 保留原有用途。

本地生成的 EXE 未做付费代码签名，发布者信息不代表模型公司或 DSH/Hermes 官方。
