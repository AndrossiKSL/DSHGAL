# DSHGAL · Unofficial learning project

A personal, experimental derivative of [JAdpp/dsh-whale-galgame](https://github.com/JAdpp/dsh-whale-galgame), with a Windows game window, existing AI-gijinka artwork and DSH / optional Hermes backends. This is a learning project with known gaps, not a stable or official product.

See the illustrated [Chinese README](README.md), [credits and original authors](CREDITS.md), [dependency license inventory](third_party/DEPENDENCIES.md), [desktop guide](docs/DESKTOP.md), and [update / repackaging guide](docs/UPDATING.md). Code, assets, fonts and the bundled workshop retain their respective terms; this is not an all-MIT artwork pack.
